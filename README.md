# VEYRAX

Оригинальная мобильная MOBA в разработке. Репозиторий ранее использовался для тестовой игры Lipa Arena; теперь основной запуск переключён на VEYRAX.

## Текущий прототип
- Godot 4.7, GDScript, Android-ориентированный интерфейс.
- Арена с центральной линией, базами и башнями двух команд.
- Прототип 5 на 5: Кайрон под управлением игрока, четыре союзника и пять противников.
- Камера сверху под углом.
- Сенсорное перемещение левой частью экрана; кнопки атаки и навыка справа.
- Простейшее преследование врагами и атака в ближнем радиусе.

## Управление
- Android: удерживайте и ведите палец по левой части экрана для движения.
- Нажимайте ATTACK или SKILL справа.
- В редакторе можно двигаться клавишами WASD.

## Запуск
Откройте проект в Godot 4.7 и запустите главную сцену `scenes/veyrax_arena.tscn`.

## План разработки
1. Проверить запуск сцены и управление на Android.
2. Добавить здоровье, урон, смерть и возрождение.
3. Реализовать полноценный ИИ союзников и противников, башни, крипов и победные условия.
4. Добавить уникальные модели, анимации, эффекты и способности пяти стартовых героев.
5. Подготовить оптимизированную Android-сборку.

## Статус
Это ранний игровой прототип, а не готовая полноценная онлайн-MOBA. Сетевая игра, прогресс, магазин предметов и отдельные 3D-модели героев ещё не реализованы.
