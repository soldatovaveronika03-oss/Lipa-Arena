# VEYRA: Clash of Realms

Новый оригинальный Unity/C# проект мобильной MOBA. Старый Godot-проект заменён; его история сохранена в ветке `backup-before-unity-reset`.

## Этап 1 — прототип
- Unity 6 (6000.0.32f1), 3D-сцена создаётся кодом.
- Камера сверху под углом.
- Карта с тремя линиями, базами и башнями.
- Выбор одного из трёх прототипных героев: Kairon (боец), Eliara (маг), Rain (стрелок).
- Команды 5 на 5: игрок + четыре союзных бота против пяти противников.
- Базовый AI, атака, три навыка, здоровье, опыт, уровни и золото.
- Экран выбора героя и мобильные экранные кнопки (OnGUI).

## Запуск
1. Установить Unity Hub и Unity Editor 6000.0.32f1.
2. Открыть папку репозитория как Unity project.
3. Открыть сцену можно не нужно: GameBootstrap создаёт арену автоматически.
4. Создать пустой GameObject в новой сцене и добавить компонент GameBootstrap.
5. Нажать Play. Для Android установить Android Build Support через Unity Hub, выбрать Android в Build Profiles и собрать APK.

## Важно
Это ранний greybox-прототип, не готовая коммерческая игра. Сейчас используются процедурные примитивы вместо финальных 3D-моделей и анимаций. Онлайн 5v5, полноценный магазин, лесные монстры/боссы, сложная система предметов, сохранения и production UI — следующие этапы.
